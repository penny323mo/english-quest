# Quiz keys changed in Stage 5

The index is the keyed choice. The source line is the dialogue sentence the item is marked against.

## J17 understand — pearl care

Source: `j17-l6` “Wipe the pearl, then put perfume on.”

| | |
| --- | --- |
| Index | 2 (unchanged) |
| Before | 戴之前噴香水，之後抹乾 |
| After | 先抹乾珍珠，再搽香水 |

The chunk blank stays `perfume`. Its pattern was “Put ___ on before you wear it, and wipe the pearl with a soft dry cloth afterwards.” It is now “Wipe the pearl, then put ___ on.” The chunk gloss was “戴之前噴香水。” and is now “先抹乾珍珠，再搽香水。”
