# Clause mismatches

Clause count is the number of sentences (`.` `?` `!` and `。` `？` `！`), ignoring dots inside quotation marks. A second count adds coordinators (`and` / `but` / `because` / `if` / `when` / `so`, and `因為` / `所以` / `如果` / `同埋` / `，想` / `，你`). The table is every line where those sentence counts differed, or where a gloss verb or object was not in the English, before this pass.

48 lines. Counts are English → Cantonese. Two more lines changed a written form without a clause-count gap: r6-l8 `寄一則短訊` is now `發個短訊`, and t2-l3 `放進` is now `放入`.
