# English Quest 1.0 試聽及試學記錄

測試版本係 1.0.0-rc.4。記低日期同裝置，可以用代號，毋須提供姓名或原始錄音。

## 打開候選版

手機開試玩站，撳「即試第一課」，聽吓 ship 同 sheep。想自己揀目標，可以用暱稱繼續設定。用同一個瀏覽器同網址做兩日練習，先可以讀返上次嘅進度。想離線試，可以喺「我」嘅設定下載完整課程包。[開啟試玩站](https://english-quest-playtest.vercel.app/) · [試聽錄音](https://english-quest-playtest.vercel.app/listen.html)

電腦亦可以下載 GitHub prerelease 嘅 `english-quest-1.0.0-rc.4.zip`，解壓後喺該資料夾開 Terminal，執行以下指令。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Mac 亦可以雙擊下載包內嘅 `Open English Quest.command`。網上試玩站、本機下載包同 0.9 正式站各自保存進度。[本機試玩](http://127.0.0.1:8765/english-quest/?trial=1) · [本機盲聽表](http://127.0.0.1:8765/listen.html)

## 英語聆聽者

選一位熟練英語使用者，喺安靜地方聽。盲聽頁打亂次序同隱藏答案。請逐題先打出聽到嘅詞或句，評估清晰度，如有難聽清嘅音，記低字頭、元音、重音或字尾。可以重播。完成後下載 CSV，入面有音檔、速度、預期字句及實際回答。若金額、藥品、目的地或意思有改變，標示要修正。再由另一位聆聽者獨立核對有爭議項。全庫另附逐檔核對證據，可以由實際檔案重聽其他案例。

## 低基礎學員

| 時間 | 學員任務 | 觀察者記錄 |
| --- | --- | --- |
| 第一天，第一次開 App | 自己揀「打好基礎」，由 F1 分辨船同羊。各做一次只聽聲同只睇字。 | 可否自己搵到入口？第一次揀中幾多題？有冇靠文字、翻譯、旁人協助？ |
| 第一天，F2 | 聽另一位同事介紹自己。唔睇示範打招呼、講自己個名，再請對方重複。 | 記實際用過嘅英文、需要邊種提示、對方聽唔聽得明。 |
| 第一天，F3 | 聽同講兩個不同時間，確認最後約幾點。 | 記低兩次實際回答，留意時間同價錢有冇混淆。 |
| 第二天，間隔至少一晚 | 開「我」，揀重練 F1、F2、F3。先做新情境，再睇提示。 | 記日期、能否分辨 seat/sit、晚上嘅招呼、八蚊同七點。比較兩日回答同提示用量。 |
| 已有經驗學員 | 喺適合自己程度嘅轉機、工作或訂貨課回應新限制，講原因同確認安排。 | 記低對方最後明白咩，回應有冇跟住新限制改變。 |

| 學員代號 | 日期／課堂 | 聽聲首次 | 認字首次 | 實際講法／對方理解 | 提示或卡住位置 | 結果 |

準備正式上線時，將每個影響意思、聽辨或下一階學習嘅發現連返課堂同音檔。修正後重做相關兩速辨音或換題重測，再記錄公開版部署同版本。
